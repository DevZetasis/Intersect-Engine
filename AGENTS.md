# Monster Taming Online Engine

This repository is an independent fork of Intersect Engine,
being developed into an online monster-catching RPG engine.

## AI Development Policy

AI-assisted development using Codex is permitted for this
independent project.

Codex may implement new features, modify existing systems,
fix bugs, and improve the engine as requested.

## Development Rules

- Preserve existing functionality unless instructed otherwise.
- Inspect relevant source code before making changes.
- Keep the server, client, and editor compatible.
- Test changes whenever possible.
- Do not modify unrelated projects or software.
- Do not commit or push changes without permission.
- Respect all existing open-source licenses and notices.
- Never submit AI-generated contributions to the official
  AscensionGameDev/Intersect-Engine repository.
